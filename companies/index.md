# 目标公司

具身智能 / 人形机器人方向，按城市整理。优先级基于：岗位与机械臂 C++ 背景的契合度、公司赛道成熟度、薪资竞争力。

## 综合优先级

```
智元机器人（SH）> 优必选（SZ）> 傅利叶智能（SH）> 非夕科技（SH）
> 乐聚机器人（SZ）> 小鹏汽车（GZ）> 大疆（SZ）
> 达闼机器人（GZ）> 开普勒 / 星动纪元（SH 初创）
```

**城市偏好权重：** 若不限城市，上海公司数量和质量均领先；深圳优必选是最稳妥的人形机器人入口；广州首选小鹏。

## 通用建议

- 现有**机械臂操控 + C++ + Linux** 背景对**运动控制 / 感知融合 / 上位机开发**岗直接有效
- ROS2 是所有目标公司的基础门槛，边投边补
- 优先投上海和深圳，广州作为补充选项
