# JD-001：C/C++（具身智能）— 京东

## 原始 JD 要点

**工作内容**
- 关节/移动机器人应用软件的开发和部署
- 视觉算法、运动控制算法的集成和部署
- 2D/3D 相机及各类机器人硬件驱动接口开发
- 物流场景（拣选、拆垛、码垛）机器人应用及界面开发
- 工业/协作机器人在物流场景下的应用研发

**任职要求**
| 要求 | 关键词 |
|------|--------|
| 语言 | C++11/14、Python |
| 系统 | Linux、多线程 |
| 通信 | Socket、WebSocket、DDS、ZMQ |
| GUI | Qt 或其他 GUI 框架 |
| 机器人 | ROS、机器视觉、运动控制 |
| 架构 | 面向对象、机器人软件架构 |

## 与当前背景的差距分析

### 已具备（推测）
- C++ 开发能力
- Qt GUI 开发经验
- 机械臂相关软件开发背景
- Linux 工作环境

### 需要补强
1. **ROS 深度使用**：不只是了解，需要有实际项目经历
2. **进程间通信**：DDS（FastDDS/CycloneDDS）、ZMQ 需要专项学习
3. **视觉算法集成**：OpenCV + 相机 SDK（RealSense、ZED 等）
4. **Python**：需要能流畅用 Python 写脚本/算法集成代码
5. **运动控制算法**：轨迹规划基础（MoveIt!）
