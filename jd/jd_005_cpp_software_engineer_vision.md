# JD-005：C++ 软件工程师（视觉 + 运控）

## 核心要求

| 维度 | 要求 |
|------|------|
| 语言 | C++ |
| GUI | VC(MFC) 或 Qt 3年+ |
| 数据库 | SQL Server/MySQL/SQLite |
| 视觉 | Halcon 或 OpenCV，C++ 下图像处理 |
| 运控 | 固高/高川控制卡 |
| 网络 | C++ 网络通信、多线程 |

## 特点

- 视觉 + 运控组合，偏传统工业视觉方向
- Halcon 是工业视觉商业软件（专业壁垒）
- 接受出差，工作强度偏高

## 与当前背景差距

- C++/Qt 满足
- 差距：Halcon 商业视觉软件、数据库开发、固高/高川控制卡
- 方向：传统工业视觉，转型价值一般
