# JD-004：QT 软件主管（人形机器人）

## 核心要求

| 维度 | 要求 |
|------|------|
| 语言 | C++/Python |
| GUI | Qt 核心模块全栈（Core/Gui/Widgets/Network/QML），信号槽深度 |
| 机器人 | ROS/QT 3年+，rosbridge/QtROS，ROS 与 Qt 桥接 |
| 平台 | Jetson、嵌入式 Linux |
| 仿真 | Gazebo、MuJoCo、Isaac Sim |
| 传感器 | 激光雷达、深度相机、IMU |

## 特点

- **主管级别**，要求独立主导项目
- Qt + ROS 深度融合，技术栈独特
- 人形机器人赛道，薪资天花板高

## 与当前背景差距

- C++/Qt 满足基础
- 差距：ROS 实战深度、仿真平台（Gazebo/MuJoCo）、Jetson 嵌入式开发
- 这是所有 JD 里技术门槛最高的，但也是薪资最好的类型之一
