# JD-006：软件开发工程师（后端）

## 核心要求

| 维度 | 要求 |
|------|------|
| 语言 | Java/Go（或 Kotlin） |
| 架构 | 微服务、DDD、OOP |
| 通信 | gRPC/Thrift、MQTT、WebSocket |
| 数据库 | NoSQL（MongoDB/Redis） |
| 工程 | CI/CD、DevOps、自动化测试 |
| 系统 | Linux、数据结构与算法、高并发低延迟 |

## 特点

- 与机器人领域**完全不同**的技术栈
- 偏互联网后端/工业 IoT 后台服务方向
- 薪资天花板较高（互联网公司）

## 与当前背景差距

- **跨度最大的 JD**，现有 C++/Qt 几乎不能直接复用
- 需要：Go 或 Java 从头学起、微服务架构、Redis/MongoDB 实战
- 准备周期：6-9 个月
- 唯一优势：Socket/WebSocket/多线程编程思维可迁移
