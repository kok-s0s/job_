# JD-007：Linux 应用工程师

## 核心要求

| 维度 | 要求 |
|------|------|
| 语言 | C/C++，Shell/Python |
| 系统 | Linux 3年+，进程/线程模型深度 |
| 网络 | TCP/IP Socket 编程，粘包处理，MQTT/CoAP |
| IPC | Pipe、FIFO、信号量、共享内存 |
| OTA | Mender/SWUpdate，分区表设计，U-Boot |
| 调试 | Core Dump 分析，性能分析工具 |
| 构建 | Makefile/CMake |

## 特点

- 偏底层 Linux 系统编程，技术深度型岗位
- OTA 升级是相对稀缺的技能点
- 涉及传感器数据采集（RTK/超声/摄像头）

## 与当前背景差距

- Linux C++ 基础满足
- 差距：IPC 深度（共享内存/信号量实战）、OTA 方案落地、Core Dump 分析
- 方向：嵌入式 Linux 应用，薪资中等
