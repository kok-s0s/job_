# ONNX Runtime C++ Demo

This project is the week 7 inference-deployment practice. It starts with a tiny ONNX model and a C++ metadata loader so the model contract can be verified before wiring a full runtime node.

## Model

`models/tiny_robot_score.onnx` is generated by `scripts/create_tiny_robot_score_onnx.py`.

Graph:

```txt
robot_features[1,3] -> MatMul(score_weight[3,1]) -> Add(score_bias[1]) -> anomaly_score[1,1]
```

The model is intentionally small. The useful engineering point is the model boundary: input name, output name, tensor element type, shape, graph nodes, and initializer tensors.

## Inference Function

`src/tiny_robot_inference.hpp` wraps the same tiny scoring rule as a deterministic C++ function:

```txt
score = robot_features[0] * 0.2 + robot_features[1] * -0.1 + robot_features[2] * 0.7 + 0.05
```

`onnx_inference_demo` verifies a fixed input:

```txt
input=[0.500,-1.000,0.200] -> score=0.390 status=OK
```

## Verify

```bash
cd projects/onnx_runtime_cpp_demo
bash scripts/verify_onnx_runtime_cpp_demo.sh
```
