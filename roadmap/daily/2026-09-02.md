# 2026-09-02：执行器状态接收程序

## 今日任务

第 8 周周三，写执行器状态接收程序，解析 CAN id、position、velocity、fault 和 fault_code。

## 代码产出

- 项目：`projects/socketcan_vcan_demo`
- 程序：`actuator_status_receiver`

状态帧约定：

```txt
id=0x180 + node_id
byte0..1 = position_mrad little-endian int16
byte2..3 = velocity_mrad_s little-endian int16
byte4 bit0 = fault
byte5 = fault_code
```

## 验收命令

```bash
cd projects/socketcan_vcan_demo
bash scripts/verify_socketcan_vcan_demo.sh
```

关键输出：

```txt
[actuator_status] raw=181#E8032C0100000000 node_id=1 position_rad=1.000 velocity_rad_s=0.300 fault=0 fault_code=0
[actuator_status] raw=182#18FC38FF01070000 node_id=2 position_rad=-1.000 velocity_rad_s=-0.200 fault=1 fault_code=7
[ok] actuator status receiver decoded position velocity and fault
```

## 复盘

CAN status receiver 的关键不是打印字节，而是把字节翻译成业务字段。position、velocity 是控制层可用的连续值，fault 和 fault_code 是状态机和安全逻辑需要立即消费的离散状态。
