## CAN 帧结构

```txt
123#1122334455667788
```

- `123`：标准 11-bit CAN id。
- `#`：id 和 payload 分隔符。
- `1122334455667788`：8 字节 payload。
- `DLC`：payload 字节数，classic CAN 范围是 0 到 8。

## SocketCAN 基础命令

```bash
sudo modprobe vcan
sudo ip link add dev vcan0 type vcan
sudo ip link set up vcan0
candump vcan0
```

## 复盘要点

- SocketCAN 把 CAN 接口当作 Linux network interface 管理。
- vcan 适合在无硬件环境下练习 CAN 报文收发。
- 后续执行器状态解析会把 id 映射成关节编号或消息类型，把 payload 映射成 position、velocity、fault 等字段。
