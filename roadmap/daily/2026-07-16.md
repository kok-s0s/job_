## 代码骨架

```cpp
#include <iostream>
#include <optional>
#include <string>
#include <string_view>
#include <variant>
#include <vector>

struct ImuSample {
    int seq{};
    double accel_x{};
    double accel_y{};
    double accel_z{};
};

std::optional<ImuSample> readImu(int seq) {
    if (seq % 4 == 0) {
        return std::nullopt;
    }

    return ImuSample{seq, 0.1 * seq, 0.2 * seq, 9.8};
}

struct StartTask {
    int task_id{};
};

struct StopTask {
    std::string reason;
};

struct FaultEvent {
    int code{};
    std::string message;
};

using RobotEvent = std::variant<StartTask, StopTask, FaultEvent>;

std::string_view commandName(std::string_view line) {
    const std::size_t pos = line.find(' ');
    if (pos == std::string_view::npos) {
        return line;
    }
    return line.substr(0, pos);
}

int main() {
    int imu_ok = 0;
    int imu_missing = 0;
    for (int seq = 0; seq < 10; ++seq) {
        const auto sample = readImu(seq);
        if (sample.has_value()) {
            ++imu_ok;
        } else {
            ++imu_missing;
        }
    }

    int events_start = 0;
    int events_stop = 0;
    int events_fault = 0;

    std::vector<RobotEvent> events{
        StartTask{1001},
        StartTask{1002},
        StopTask{"operator request"},
        FaultEvent{42, "imu timeout"},
    };

    for (const auto& event : events) {
        std::visit([&](const auto& value) {
            using T = std::decay_t<decltype(value)>;
            if constexpr (std::is_same_v<T, StartTask>) {
                ++events_start;
            } else if constexpr (std::is_same_v<T, StopTask>) {
                ++events_stop;
            } else if constexpr (std::is_same_v<T, FaultEvent>) {
                ++events_fault;
            }
        }, event);
    }

    const std::string move = "MOVE joint_1 1.57";
    const std::string stop = "STOP emergency";
    const std::string status = "STATUS";

    std::cout << "imu_ok: " << imu_ok << '\n';
    std::cout << "imu_missing: " << imu_missing << '\n';
    std::cout << "events_start: " << events_start << '\n';
    std::cout << "events_stop: " << events_stop << '\n';
    std::cout << "events_fault: " << events_fault << '\n';
    std::cout << "cmd_move: " << commandName(move) << '\n';
    std::cout << "cmd_stop: " << commandName(stop) << '\n';
    std::cout << "cmd_status: " << commandName(status) << '\n';

    const bool pass = imu_ok == 7 &&
                      imu_missing == 3 &&
                      events_start == 2 &&
                      events_stop == 1 &&
                      events_fault == 1 &&
                      commandName(move) == "MOVE" &&
                      commandName(stop) == "STOP" &&
                      commandName(status) == "STATUS";

    std::cout << "result: " << (pass ? "pass" : "fail") << '\n';
    return pass ? 0 : 1;
}
```

## C++17 类型工具面试笔记

1. `std::optional<T>` 表示“可能没有 T”，适合传感器读取失败、参数不存在、查表无结果这类场景。
2. `optional` 比魔法值更清晰，因为调用方必须显式判断 `has_value()` 或 `if (value)`。
3. `std::variant<A, B, C>` 表示值只能是有限几种类型之一，适合机器人事件、状态结果、错误详情。
4. `variant` 比裸 `union` 安全，因为它知道当前持有哪种类型，并能配合 `std::visit` 做类型分发。
5. `std::string_view` 不拥有字符串，只是指向一段已有字符内存，适合解析命令、日志和协议字段。
6. `string_view` 不能保存超过原字符串生命周期，尤其不能返回指向临时 `std::string` 或局部缓冲区的 view。
7. 在异步线程、队列、长期对象里保存字符串时，应该用 `std::string` 拥有数据，而不是 `string_view`。

## 常见错误

- 用 `-1`、空字符串、特殊枚举值表达“缺失”，导致调用方不清楚是否必须处理失败。
- `variant` 里放过多不相关类型，反而让事件模型失控。
- `std::visit` 里忘记处理某个类型，业务逻辑遗漏。
- `string_view` 保存了临时 `std::string` 的内容地址，临时对象销毁后 view 悬空。
- 把 `string_view` 当成字符串所有者，在异步线程或长期对象里保存它。

## 面试表达模板

> `optional` 适合表达“可能没有值”的结果，比魔法值更明确。`variant` 适合表达有限几种互斥类型，比如机器人事件、状态结果或错误详情，比裸 union 安全。`string_view` 适合解析命令、日志、协议字段时避免拷贝，但它不拥有内存，不能保存超过原始字符串生命周期。
