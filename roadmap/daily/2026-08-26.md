## 固定输入

```txt
robot_features = [0.500, -1.000, 0.200]
score = 0.500 * 0.2 + -1.000 * -0.1 + 0.200 * 0.7 + 0.05 = 0.390
status = OK
```

## 验收命令

```bash
cd projects/onnx_runtime_cpp_demo
bash scripts/verify_onnx_runtime_cpp_demo.sh
```

关键输出：

```txt
[inference] model=tiny_robot_score input=[0.500,-1.000,0.200] score=0.390 status=OK
[ok] fixed input inference stable
```

## 复盘要点

- 推理函数先保证确定性，再谈接入框架和实时系统。
- 输入校验要前置，非有限值应当直接报错，而不是继续传播异常结果。
- 真实接 ONNX Runtime 时，`run()` 可以替换为 `Ort::Session::Run()`，但外层输入输出契约保持稳定。
