# 2026-09-04：CAN 接入状态机验收

## 今日任务

第 8 周周五，把 CAN 超时和执行器 fault 位接入 runtime 状态机语义：通信超时或设备上报故障时，都要能映射到 `FAULT`。

## 代码产出

- 项目：`projects/socketcan_vcan_demo`
- 程序：`can_runtime_fault_bridge`

故障规则：

```txt
status age_ms > 100 -> FAULT / CAN_TIMEOUT
status byte4 bit0 == 1 -> FAULT / CAN_ACTUATOR_FAULT
```

## 验收命令

```bash
cd projects/socketcan_vcan_demo
bash scripts/verify_socketcan_vcan_demo.sh
```

关键输出：

```txt
[can_watchdog] now_ms=150 age_ms=150 timeout_ms=100 state=FAULT error=CAN_TIMEOUT
[can_bridge] now_ms=0 raw=182#18FC38FF01070000 state=FAULT error=CAN_ACTUATOR_FAULT
[ok] CAN timeout and actuator fault map to runtime Fault
```

## 复盘

这周的闭环是：CAN 帧结构 -> vcan 收发 -> 执行器状态解析 -> 周期控制命令 -> 故障接入状态机。面试表达可以收束成一句话：我把硬件通信异常翻译成 runtime 可观测、可恢复、可验证的状态机事件。
