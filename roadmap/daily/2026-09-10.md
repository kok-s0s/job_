# 2026-09-10：模拟传感器挂到 link

## 今日任务

第 9 周周四，把模拟 IMU 传感器 frame 挂到机械臂 link 上。今天将 `imu_link` 通过 fixed joint 挂到 `elbow_link`，为后续 rviz2 显示传感器坐标系做准备。

## 代码产出

- 项目：`projects/urdf_two_joint_arm_demo`
- 模型：`models/two_joint_arm.urdf`
- 程序：`sensor_frame_mount_check`

挂载关系：

```txt
elbow_link --imu_mount_joint(fixed)--> imu_link
origin xyz="0.25 0 0.08"
```

## 验收命令

```bash
cd projects/urdf_two_joint_arm_demo
bash scripts/verify_urdf_two_joint_arm_demo.sh
```

关键输出：


## 复盘

传感器 frame 要挂到明确的机械结构上。这样 IMU、相机、力传感器等数据的 `header.frame_id` 才能和 robot model 的 TF 树对齐，后续定位问题时可以判断数据来自哪个物理位置。
