## 练习题

### 题目 1：确认录制对象

今天录制 3 个 Topic：

```txt
/robot/imu
/robot/joint_states
/runtime/heartbeat
```

这三类数据能覆盖一次运行时现场：

- IMU：高频传感器新鲜度和数据节奏。
- JointState：关节状态形状、名称、位置和更新时间。
- Heartbeat：节点存活证据和 watchdog 判断依据。

### 题目 2：手动录制命令

启动 demo 后执行：

```bash
ros2 bag record -o runtime_capture /robot/imu /robot/joint_states /runtime/heartbeat
```

停止后检查：

```bash
ros2 bag info runtime_capture
```

验收：输出中能看到 3 个 Topic，并且 message count 大于 0。
