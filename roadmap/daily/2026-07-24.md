## 练习题

### 题目 1：创建自定义 Action 接口

在 package 中新增：

```txt
projects/ros2_runtime_demo/src/robot_runtime_demo/action/ExecuteTask.action
```

接口内容：

```action
int32 target_steps
---
bool success
string message
---
int32 current_step
float32 progress
```

要求：

- `target_steps` 必须大于 0。
- feedback 的 `progress` 范围为 `0.0` 到 `1.0`。
- result 能区分完成、取消和失败。
- 在 `CMakeLists.txt` 与 `package.xml` 中补齐 Action 接口生成依赖。

提示依赖：

```txt
action_msgs
rosidl_default_generators
rosidl_default_runtime
```

### 题目 2：实现 Action server

在 `runtime_node.cpp` 中创建：

```txt
/runtime/execute_task
```

建议拆成 3 个处理函数：

```cpp
handleGoal(...)
handleCancel(...)
handleAccepted(...)
```

要求：

- 非法 goal（`target_steps <= 0`）返回 reject。
- 合法 goal 返回 accept。
- 允许客户端取消任务。
- 执行过程不能阻塞 ROS2 executor 的其他 callback。
- 每完成一步发布一次 feedback。
- 每一步休眠约 200 ms，方便观察进度。

建议先画出控制流程：

```txt
收到 goal
  → 校验 target_steps
  → 接受并启动执行线程
  → 循环检查 cancel
  → 发布 feedback
  → succeed / canceled
```

### 题目 3：处理完成与取消

执行循环至少覆盖以下 3 条路径：

1. 正常完成：调用 `goal_handle->succeed(result)`。
2. 客户端取消：调用 `goal_handle->canceled(result)`。
3. 节点停止：安全退出执行逻辑，不留下失控线程。

正常完成时，result 建议返回：

```txt
success=true
message="task completed"
```

取消时，result 建议返回：

```txt
success=false
message="task canceled at step N"
```

额外挑战：

- 执行期间把 runtime 状态改为 `RUNNING`。
- 任务完成或取消后恢复为 `IDLE`。
- 同一时刻只允许一个 active goal。

### 题目 4：命令行验收

构建并启动：

```bash
cd projects/ros2_runtime_demo
source /opt/ros/jazzy/setup.bash
colcon build --packages-select robot_runtime_demo
source install/setup.bash
ros2 launch robot_runtime_demo runtime_demo.launch.py
```

另开终端检查接口：

```bash
source /opt/ros/jazzy/setup.bash
cd projects/ros2_runtime_demo
source install/setup.bash

ros2 action list -t
ros2 interface show robot_runtime_demo/action/ExecuteTask
ros2 action send_goal --feedback \
  /runtime/execute_task \
  robot_runtime_demo/action/ExecuteTask \
  "{target_steps: 10}"
```

取消测试：

```bash
ros2 action send_goal --feedback \
  /runtime/execute_task \
  robot_runtime_demo/action/ExecuteTask \
  "{target_steps: 30}"
```

在任务执行期间按 `Ctrl+C`，观察 server 是否进入取消路径。若 CLI 没有发送 cancel，请使用 `--help` 确认当前 ROS2 发行版的取消操作，或写一个最小 Action client 做取消测试。
