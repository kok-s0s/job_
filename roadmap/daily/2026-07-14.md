## 代码骨架

```cpp
#include <condition_variable>
#include <iostream>
#include <mutex>
#include <numeric>
#include <queue>
#include <thread>
#include <vector>

class BlockingQueue {
public:
    BlockingQueue() = default;
    BlockingQueue(const BlockingQueue&) = delete;
    BlockingQueue& operator=(const BlockingQueue&) = delete;

    void push(int value) {
        {
            std::lock_guard<std::mutex> lock(mutex_);
            if (stopped_) {
                return;
            }
            queue_.push(value);
        }
        cv_.notify_one();
    }

    bool pop(int& value) {
        std::unique_lock<std::mutex> lock(mutex_);
        cv_.wait(lock, [this] {
            return stopped_ || !queue_.empty();
        });

        if (queue_.empty()) {
            return false;
        }

        value = queue_.front();
        queue_.pop();
        return true;
    }

    void shutdown() {
        {
            std::lock_guard<std::mutex> lock(mutex_);
            stopped_ = true;
        }
        cv_.notify_all();
    }

private:
    std::mutex mutex_;
    std::condition_variable cv_;
    std::queue<int> queue_;
    bool stopped_{false};
};

int main() {
    BlockingQueue queue;

    constexpr int message_count = 1000;
    int consumed_count = 0;
    long long sum = 0;

    std::thread consumer([&] {
        int value = 0;
        while (queue.pop(value)) {
            ++consumed_count;
            sum += value;
        }
    });

    std::thread producer([&] {
        for (int i = 0; i < message_count; ++i) {
            queue.push(i);
        }
        queue.shutdown();
    });

    producer.join();
    consumer.join();

    const long long expected_sum = 1LL * (message_count - 1) * message_count / 2;
    const bool pass = consumed_count == message_count && sum == expected_sum;

    std::cout << "produced: " << message_count << '\n';
    std::cout << "consumed: " << consumed_count << '\n';
    std::cout << "sum: " << sum << '\n';
    std::cout << "result: " << (pass ? "pass" : "fail") << '\n';

    return pass ? 0 : 1;
}
```

## condition_variable 面试笔记

1. `cv_.wait(lock)` 不能单独使用，因为线程可能被虚假唤醒，醒来后条件并不一定满足。
2. `wait(lock, predicate)` 等价于在循环里反复检查条件，只有谓词为真才继续执行。
3. 生产者 `push()` 后调用 `notify_one()`，因为只需要唤醒一个消费者来处理新消息。
4. `shutdown()` 要调用 `notify_all()`，因为可能有多个消费者阻塞在空队列上，都需要被唤醒检查停止标志。
5. 如果消费者一直阻塞且没人通知，它无法退出，主线程 `join()` 会一直等待，程序就会卡死。

## 常见错误

- `wait` 不带谓词，遇到虚假唤醒后可能读空队列。
- `shutdown()` 后没有 `notify_all()`，消费者可能永远睡眠。
- 在持锁状态下执行很慢的业务逻辑，导致生产者被阻塞。
- 忘记 `join()`，主线程提前结束或触发 `std::terminate`。
- `consumed_count` 和 `sum` 如果被多个消费者同时写，需要额外同步；今天先做单消费者，避免混淆主线。

## 面试表达模板

> 生产者消费者队列的核心是用 mutex 保护共享队列，用 condition_variable 避免消费者空转。消费者用 `wait(lock, predicate)`，谓词同时检查“队列非空”和“系统停止”，这样可以处理虚假唤醒，也能在 shutdown 时正常退出。push 数据后用 `notify_one` 唤醒一个消费者；shutdown 时用 `notify_all`，保证所有阻塞线程都有机会退出。
