# 2026-09-03：50Hz 周期命令发送程序

## 今日任务

第 8 周周四，写周期命令发送程序，按 50Hz 生成模拟控制帧。今天不依赖实时线程，先把 20ms 周期、CAN id 和 payload 编码固化成可验证输出。

## 代码产出

- 项目：`projects/socketcan_vcan_demo`
- 程序：`periodic_command_sender`

命令帧约定：

```txt
id=0x200 + node_id
byte0..1 = target_position_mrad little-endian int16
byte2..3 = target_velocity_mrad_s little-endian int16
byte4 = enable flag
```

## 验收命令

```bash
cd projects/socketcan_vcan_demo
bash scripts/verify_socketcan_vcan_demo.sh
```

关键输出：

```txt
[command_sender] target_hz=50 period_ms=20 sample_count=10
[command_tx] tick=9 t_ms=180 cansend="cansend vcan0 201#..."
[ok] periodic command sender generated 50Hz control frames
```

## 复盘

周期控制命令要能回答两个问题：频率是多少、payload 代表什么。50Hz 对应 20ms，一旦发送端堵塞或状态端超时，上层 runtime 应该能从日志里看出控制链路是否健康。
