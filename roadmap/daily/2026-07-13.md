### 题目 1：手写 ResourceGuard

写一个 `ResourceGuard` 类，模拟管理机器人系统里的底层资源，例如传感器句柄、CAN 设备句柄或日志文件句柄。

要求：

- 构造函数打印 `open resource: <name>`。
- 析构函数打印 `close resource: <name>`。
- 禁止拷贝构造和拷贝赋值。
- 支持移动构造和移动赋值。
- 移动后，原对象不再负责关闭资源。
- 在 `main()` 里演示所有权转移。

建议文件名：

```txt
practice/today_2026_07_13_raii.cpp
```

代码骨架：

```cpp
#include <iostream>
#include <memory>
#include <string>
#include <utility>

class ResourceGuard {
public:
    explicit ResourceGuard(std::string name)
        : name_(std::move(name)), valid_(true) {
        std::cout << "open resource: " << name_ << '\n';
    }

    ~ResourceGuard() {
        if (valid_) {
            std::cout << "close resource: " << name_ << '\n';
        }
    }

    ResourceGuard(const ResourceGuard&) = delete;
    ResourceGuard& operator=(const ResourceGuard&) = delete;

    ResourceGuard(ResourceGuard&& other) noexcept
        : name_(std::move(other.name_)), valid_(other.valid_) {
        other.valid_ = false;
    }

    ResourceGuard& operator=(ResourceGuard&& other) noexcept {
        if (this == &other) {
            return *this;
        }

        if (valid_) {
            std::cout << "close resource: " << name_ << '\n';
        }

        name_ = std::move(other.name_);
        valid_ = other.valid_;
        other.valid_ = false;
        return *this;
    }

    void use() const {
        if (valid_) {
            std::cout << "use resource: " << name_ << '\n';
        }
    }

private:
    std::string name_;
    bool valid_{false};
};

int main() {
    ResourceGuard imu("imu-driver");
    imu.use();

    ResourceGuard owner = std::move(imu);
    owner.use();

    ResourceGuard can("can-device");
    can = std::move(owner);
    can.use();

    return 0;
}
```

## 智能指针面试笔记

1. `unique_ptr` 表示独占所有权，适合传感器连接、设备句柄、日志文件、线程对象这类生命周期明确的资源。
2. `shared_ptr` 表示共享所有权，适合多个模块确实需要共同延长对象生命周期的场景，但不应该作为默认选择。
3. `shared_ptr` 的风险是所有权变得不清晰，引用计数也有成本，还可能因为循环引用导致对象永远不析构。
4. `weak_ptr` 不拥有对象，只观察 `shared_ptr` 管理的对象，适合监控器、回调、父子关系中的反向引用。
5. 在机器人系统里，硬件句柄、实时线程、控制器对象、执行器连接不应该随便 `shared`，否则释放顺序不确定会放大故障风险。

## 面试表达模板

> RAII 的核心是把资源生命周期绑定到对象生命周期。机器人软件里有很多必须确定释放的资源，比如传感器连接、CAN 设备、日志文件、线程句柄。用 RAII 可以保证异常或提前返回时资源仍然会在析构函数里释放。单一所有权用 `unique_ptr`，共享读写关系要谨慎用 `shared_ptr`，如果只是观察对象生命周期，优先用裸引用、裸指针或 `weak_ptr`，避免循环引用和不清晰的所有权。
